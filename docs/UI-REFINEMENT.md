## 本轮设计
- 白色为主背景，深灰文字，蓝色用于主操作、选中状态及数据变化；橙色用于超限，红色用于错误。
- 摘要合并为一个区域，减少悬浮卡片与渐变；持仓表和模拟面板保留明确结构。
- 放大表格、说明和输入文字，统一间距、圆角、线条及数字对齐，减少装饰性英语标语。
- 调仓后突出发生变化的持仓行，保留原始值 → 模拟值。
- 保留现有数据流、后端规则与保存方式。
